# 學測數學｜108–115 歷屆試題練習室

這是可直接放在 **GitHub Pages** 的靜態網站，風格延續 K7000 單字練習室，但獨立成一個數學專案。

## 收錄範圍

- 108、109、110 學年度：舊制「數學」，各 1 份，共 3 份。
- 111、112、113、114、115 學年度：各有「數學 A」及「數學 B」，共 10 份。
- **合計 13 份官方試卷。** 官方試卷、答案及 111–115 年非選題評分原則，皆透過大考中心公開 PDF 連結閱讀；網站本身不另行分發試卷 PDF。

## 功能

- 年度、考科篩選（預設數學 A）。
- 官方試題 PDF 另開／內嵌預覽（視瀏覽器 PDF 政策而定）。
- 線上單選、多選、選填答題卡，111–115 年非選題草稿區。
- 100 分鐘計時（可暫停、重設）。
- 選擇與選填答案核對；錯題筆記與個人標註章節。
- 成績統計、瀏覽器內自動儲存，JSON 紀錄備份。
- 手機／桌面排版，免註冊、無後端服務。

## 上線步驟

1. 登入 GitHub，建立一個 **Public** repository，例如 `GSAT-Math`。
2. 將本資料夾的 `index.html` 上傳到 repository 的根目錄（同層 `README.md` 可選擇一併上傳）。
3. 在 repository 的 **Settings → Pages**，選擇 **Deploy from a branch**，Branch 選 `main`，資料夾選 `/(root)`，按 Save。
4. 部署完成後開啟 `https://你的帳號.github.io/GSAT-Math/`。網頁尚未部署前，此網址不會顯示網站。

> 整個網站程式及答題資料已放在單一 `index.html`；`exam-data.json` 是供將來更新題庫用的備份，**不用上傳**也可正常執行。

## 注意事項

1. **不是大考中心官方網站。** 來源：<https://www.ceec.edu.tw/xmfile?xsmsid=0J052424829869345634>。
2. 選擇（填）題的批改只比較整題完全正確與否，**沒有套用多選題部分給分規則**，因此結果不是正式得分或 15 級分。
3. 新制第 19、20 題屬非選擇題，需參照官方評分原則由老師或考生人工評閱，網站只儲存作答草稿。
4. 選填題依**答題卷每一列**核對數字與負號；正式配分與得分規定以各年試卷為準。
5. 答題、錯題、筆記只保存在本機瀏覽器的 `localStorage`，不會上傳至任何伺服器；換電腦、清除瀏覽資料時可能遺失。
6. PDF 是否可在 iframe 預覽取決於大考中心伺服器與瀏覽器政策；若預覽失敗，按「另開官方試卷 PDF」閱讀即可。

## 開發補充

`index.html` 內的 `EXAMS` 物件包含各年度官方 PDF 連結與選擇（填）題參考答案。更新資料時，務必再核對官方公開的 **選擇（填）題參考答案**，特別留意負號、單選／多選界線和選填列號。並請不要把自編題目標示成官方原題。


## 新增：單元與名校段考逐題練習

- 點「名校段考・單題練習」分頁。
- 可以勾選高一上、高一下、高二上、高二下、高三上（跨學期複選）。
- 再勾單元、篩選 111–115 年的年度及學校，一次僅顯示一題。
- 支援答案解析、上一題／下一題、已作答與待複習紀錄，資料留在瀏覽器 localStorage。
- 段考來源索引包含可核對的校卷連結；本站練習題是同類型改寫及自編題，**不是全部原卷逐字轉載**。
- 高三上屬選修延伸，與學測數A、數B範圍請區分。
- 新增檔案只需替換 `index.html`，其他頁面原有功能不受影響。
